# Практика. Исправление ошибок в оценке портфеля

Выберите одну карточку. На исправление и повторную проверку отведите около 20 минут. Д4 подходит для общего разбора, а Д1 и Д5 можно взять для более короткой самостоятельной работы.

Откройте корневой Maven-проект на JDK 25. Выполните команду карточки до первой правки, затем повторите её после исправления. В IDE запустите одноимённый метод в классе `PracticeStarterChecks`. Проверяемые сценарии находятся в `PracticeContracts`, правки вносите в [DefectStarters.java](../../../src/test/java/academy/backend/market_pulse/portfolio/practice/DefectStarters.java). На разборе покажите порядок событий, который приводил к сбою, и объясните, что теперь проверяет тест.

## Д1. Поставщик перестал принимать запросы

Во время пакетной оценки поставщик котировок отвечает 503 на один запрос. Market Pulse сообщает об ошибке для этого портфеля, но следующий портфель тоже остаётся без цены, хотя у поставщика уже нет активных запросов.

**Что увидеть.** При квоте 1 тест удерживает первый запрос внутри загрузчика и запускает второй. Первый завершается с HTTP 503, второй в исходном варианте не успевает получить цену. После правки второй возвращает цену в пределах тайм-аута. Максимум одновременных обращений равен одному, после обоих вызовов разрешение снова доступно.

**Где начать.** `DefectStarters#loadWithQuota`. Выполните проверку и проследите состояние разрешения при исключении из загрузчика.

```bash
mvn -pl advanced '-Dtest=PracticeStarterChecks#d1' test
```

## Д2. Две загрузки одной цены

В двух одновременно оцениваемых портфелях есть акции Т-Технологий (тикер `T`). Оба получают верную цену, но два одинаковых запроса расходуют квоту поставщика и добавляют сетевую нагрузку.

**Что увидеть.** Тест удерживает первую загрузку и запрашивает цену `T` второй раз, пока цена ещё не опубликована. В заготовке счётчик показывает два обращения. После исправления оба вызывающих кода получают цену, счётчик показывает одно обращение.

**Где начать.** `DefectStarters#loadCachedQuote`. Найдите чтение карты и то место, где результат появляется в ней после запроса.

```bash
mvn -pl advanced '-Dtest=PracticeStarterChecks#d2' test
```

## Д3. Оценка зависла в пуле из одного потока

Для фоновой оценки Market Pulse выделен один рабочий поток. Задача уже получила этого работника, но потребитель так и не дожидается загруженной цены.

**Что увидеть.** У исходной заготовки ожидание `Future` в тесте заканчивается тайм-аутом. После правки переданный загрузчик выполняется на работнике `single-worker` и цена возвращается вызывающему коду вовремя.

**Где начать.** `DefectStarters#evaluateOnOneWorker`. Найдите оба места подачи задачи и восстановите, где находится каждая из них в момент ожидания.

```bash
mvn -pl advanced '-Dtest=PracticeStarterChecks#d3' test
```

</details>

## Д4. Отчёт объявили готовым слишком рано

Основные котировки недоступны, и Market Pulse переключается на резерв. Клиент уже видит статус «готово», хотя сумма ещё не рассчитана и пользователю пока нечего показать.

**Что увидеть.** Тест завершает основной стейдж ошибкой 503 и удерживает резервный. В исходной заготовке внешний стейдж уже завершён. После исправления резерв вызывается один раз и итоговый стейдж остаётся незавершённым до его ответа. Затем вызывающий код получает резервный отчёт либо ошибку резерва.

**Где начать.** `DefectStarters#recoverReportWithBackup`. Посмотрите на типы выражения в обработчике и результата всей цепочки.

```bash
mvn -pl advanced '-Dtest=PracticeStarterChecks#d4' test
```

## Д5. Свежая цена исчезла

Market Pulse обновляет цены на странице портфеля. Запрос с новым значением AAPL успевает первым. Поздний ответ предыдущего запроса откатывает цену, хотя пользователь уже видел более свежую оценку.

**Что увидеть.** Проверка передаёт для AAPL версию 2, затем версию 1. Заготовка отдаёт значение из последнего полученного ответа. После исправления читатель видит версию 2 вместе с её ценой, а запись другого тикера `T` сохраняет своё значение.

**Где начать.** `DefectStarters#publishQuote` и `DefectStarters#publishedQuote`. Проверьте правку на заданном порядке доставки и мысленно переставьте операции двух одновременных обновлений.

```bash
mvn -pl advanced '-Dtest=PracticeStarterChecks#d5' test
```
