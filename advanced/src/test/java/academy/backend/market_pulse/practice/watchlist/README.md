# Подписки меняются во время обхода

Market Pulse обновляет котировки по небольшому списку подписок каждую секунду. Пользователь меняет его несколько раз за день. Во время одного обхода он удалил `GAZP` и добавил `LKOH`. При попытке перейти к следующему тикеру возникло исключение `ConcurrentModificationException`.

## Что исправить

Подберите коллекцию для `WatchList`. Поток интерфейса может менять подписки, пока поток обновления обходит тикеры. Вызов `startRefresh()` должен зафиксировать состав и порядок тикеров на начало обхода. Правки попадут в следующий обход. Повторная подписка на тот же тикер сохраняет одну запись в исходной позиции. [Заготовка WatchList.java](WatchList.java)

## Самопроверка

Из корня репозитория выполните команду до правки и после неё.

```bash
mvn -pl advanced -Dtest=WatchListCheck test
```

Тест задаёт порядок событий в одном потоке. Итератор уже вернул `SBER`, затем изменились подписки. Текущий обход должен дочитать `GAZP`, следующий должен выдать `SBER` и `LKOH`. [WatchListCheck.java](WatchListCheck.java)
