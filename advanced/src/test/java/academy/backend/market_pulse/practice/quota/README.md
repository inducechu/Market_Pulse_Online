# Квота поставщика котировок

Два клиента Market Pulse используют один ключ доступа к поставщику и делят общий семафор. Каждый активный запрос занимает одно разрешение. Когда поставщик отвечает ошибкой, активных запросов становится меньше, но освободившееся место пропадает из квоты.

## Что исправить

Доработайте метод `QuoteQuota.refresh`. До обращения к поставщику клиент должен получить одно разрешение из переданного семафора. После успеха или ошибки запроса оно возвращается в общую квоту. Исключение от поставщика получает вызывающий код. Если ожидание разрешения прервано, вызывающий код получает `InterruptedException`, а число разрешений остаётся прежним. [Заготовка QuoteQuota.java](QuoteQuota.java)

## Самопроверка

Из корня репозитория выполните команду до правки и после неё.

```bash
mvn -pl advanced -Dtest=QuoteQuotaCheck test
```

В тесте поставщик выбрасывает исключение при квоте в одно место. Проверка сразу сверяет количество свободных разрешений до следующего запроса. Ещё два сценария охватывают успешный запрос и прерывание до захвата. [QuoteQuotaCheck.java](QuoteQuotaCheck.java)
