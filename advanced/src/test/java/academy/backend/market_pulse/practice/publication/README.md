# Публикация первой котировки

Один поток получает цену от поставщика, а поток интерфейса периодически читает `current()`. Для каждой загрузки создаётся отдельный `QuotePublication`. Иногда карточка показывает 0 копеек ещё до первого ответа.

## Что исправить

Доработайте метод `QuotePublication.publishWhenReady`. Используйте обычное поле для цены и имеющийся `volatile`-флаг готовности. До успешного ответа `current()` возвращает `OptionalInt.empty()`. Читатель, который увидел `ready == true`, должен получить цену из ответа. При ошибке поставщика цена остаётся неопубликованной, а возвращённый `CompletableFuture` завершается с ошибкой. [Заготовка QuotePublication.java](QuotePublication.java)

## Самопроверка

Из корня репозитория выполните команду до правки и после неё.

```bash
mvn -pl advanced -Dtest=QuotePublicationCheck test
```

Тест явно задаёт момент ответа. Первое чтение происходит при незавершённом запросе, второе после `publication.get()`. Так тест ловит преждевременный сигнал готовности. В приложении интерфейс читает `current()` напрямую, поэтому видимость цены обоснуйте через порядок действий и правило для `volatile` в Java Memory Model. [QuotePublicationCheck.java](QuotePublicationCheck.java), [JLS 17.4.5](https://docs.oracle.com/javase/specs/jls/se25/html/jls-17.html#jls-17.4.5)
