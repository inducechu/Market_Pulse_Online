# Счётчик просмотров карточки акции

Два пользователя открывают карточку одной бумаги. У первого экран загружается дольше. Оба в итоге видят котировку, а в статистике отображается один просмотр.

## Что исправить

Доработайте метод `ViewCounter.openCard`. Каждый успешно показанный экран прибавляет ровно один просмотр к общему счётчику. Если `render.run()` выбрасывает исключение, число просмотров остаётся прежним. Пользователи могут открывать карточки параллельно. [Заготовка ViewCounter.java](ViewCounter.java)

## Самопроверка

Из корня репозитория выполните команду до правки и после неё.

```bash
mvn -pl advanced -Dtest=ViewCounterCheck test
```

Тест останавливает первый показ внутри `render`. Пока он ждёт, второй поток успевает показать карточку и завершиться. После завершения первого показа тест ожидает два просмотра. Отдельный сценарий проверяет ошибку при показе. [ViewCounterCheck.java](ViewCounterCheck.java)
